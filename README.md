# dylan.jbf.com

Searchable index of Bob Dylan’s official catalog and short, widely cited quotations — for writing, talks, and discussion. Full lyrics stay on [bobdylan.com](https://www.bobdylan.com/).

- Live: https://dylan.jbf.com
- Rebuild pages: `python3 build.py` (reads `/workspace/dylan-src` catalog metadata and `data/quotes-raw.tsv`)

Curated quotations only; the official song and album lists come from bobdylan.com (titles, years, tracklists, play counts — not lyric pages).
